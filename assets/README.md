# Profile artwork and data

- `header.svg` / `footer.svg`: generated for Olimjon Tojiboev with the public [capsule-render](https://github.com/kyechan99/capsule-render) image service.
- Icons, dividers, workflow graphic and milestone tiles: original SVG artwork created for this profile.

No paid service, API credential, private GitHub token, browser session, private contribution query or scheduled workflow is needed by these assets.
